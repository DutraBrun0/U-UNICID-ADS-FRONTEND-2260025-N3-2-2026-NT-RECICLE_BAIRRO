Orçamento de hospedagem

Quanto custa colocar o site no ar

O Reciclê Bairro é um site estático (HTML, CSS e JavaScript), o que permite hospedagem gratuita. Abaixo, as opções comparadas.

Opções de hospedagem (valores de referência, aproximados)
OpçãoIndicada paraCusto mensalObservações
GitHub PagesSites estáticosR$ 0HTTPS incluso; domínio próprio opcional; sem back-end.
Netlify, Cloudflare Pages ou Vercel (plano gratuito)Sites estáticos com publicação automáticaR$ 0Há limites de uso no plano gratuito.
Hospedagem compartilhadaSites com PHP, WordPress e e-mail própriocerca de R$ 10 a R$ 30Painel pronto; desempenho varia conforme o plano.
VPSAplicações com back-end e banco de dadoscerca de R$ 30 a R$ 100 ou maisExige administrar o servidor, com mais controle.

Os preços dos provedores mudam com frequência: confira na página oficial de cada um antes de contratar.

Cenário recomendado

Hospedagem gratuita com domínio próprio.

  • R$ 0hospedagem no GitHub Pages
  • R$ 40domínio .com.br por ano, no Registro.br
  • ≈ R$ 3,33custo mensal total

Como publicar no GitHub Pages

  1. Crie um repositório

    No GitHub, crie um repositório público para o projeto.

  2. Envie os arquivos

    Suba as páginas, o style.css e a pasta img.

  3. Ative o Pages

    Em Settings, abra Pages e escolha a branch principal como origem.

  4. Acesse o endereço

    Em alguns minutos o site fica disponível no endereço gerado pelo GitHub.
