# Reciclê Bairro
 
Site institucional sobre reciclagem e impacto social, que mapeia pontos de coleta seletiva e aproxima moradores das cooperativas de catadores da Zona Leste de São Paulo.
 
Projeto da **Atividade A2 de Front-End** — Engenharia de Software, UNICID (2026).
 
## Páginas
 
| Página | Arquivo | Conteúdo |
|---|---|---|
| Início | `index.html` | Apresentação, problema, números e destaque de acessibilidade |
| Sobre | `sobre.html` | História, missão, visão e valores |
| Projetos | `projetos.html` | Pontos de coleta, frentes de atuação, depoimentos e formulário de avaliação |
| Impacto | `impacto.html` | Resultados, benefícios e como participar |
| Acessibilidade | `acessibilidade.html` | O que o site faz por cada tipo de deficiência |
| Galeria | `galeria.html` | Registros das ações |
| Mídia | `midia.html` | Guia das cores da coleta seletiva e dicas de descarte |
| Notícias | `noticias.html` | Matéria sobre descarte irregular de resíduos |
| Contato | `contato.html` | E-mail, telefone e formulário de mensagem |
| Orçamento de hospedagem | `hospedagem.html` | Comparativo de hospedagem e domínio |
 
## Estrutura
 
```
Reciclê bairro/
├── index.html
├── sobre.html
├── projetos.html
├── impacto.html
├── acessibilidade.html
├── galeria.html
├── midia.html
├── noticias.html
├── contato.html
├── hospedagem.html
├── style.css        # CSS único, compartilhado por todas as páginas
├── img/             # ilustrações em SVG
└── docs/            # documentação e capturas de tela
```
 
## Como executar
 
Não precisa instalar nada. Baixe a pasta e abra o `index.html` no navegador.
 
## Tecnologias
 
- HTML5 semântico
- CSS3 (um único arquivo, sem frameworks)
- Sem JavaScript
## Acessibilidade
 
- Link "Pular para o conteúdo" no início de cada página
- Navegação completa pelo teclado, com foco visível
- Estrutura semântica (`header`, `nav`, `main`, `footer`) e títulos em ordem
- Texto alternativo nas imagens e rótulo em todos os campos de formulário
- Informações que nunca dependem só da cor
- Layout responsivo (celular, tablet e computador)
Os detalhes por tipo de deficiência estão na página `acessibilidade.html`.
 
## Publicação
 
Por ser um site estático, pode ser publicado de graça no **GitHub Pages**:
 
1. Envie os arquivos para um repositório público.
2. Em *Settings → Pages*, escolha a branch principal como origem.
3. Acesse o endereço gerado pelo GitHub.
O comparativo completo de custos está em `hospedagem.html`.
 
## Observações
 
- Depoimentos, e-mail e telefone são **fictícios**, criados para este projeto acadêmico.
- Os formulários são apenas demonstrativos e não enviam dados.
- As imagens em `img/` são ilustrações provisórias, a serem trocadas por fotos reais.
- A notícia da página `noticias.html` cita dados da Prefeitura de Praia Grande (04/09/2026).
